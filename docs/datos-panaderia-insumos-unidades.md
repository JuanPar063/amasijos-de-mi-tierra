## 2. Fórmulas (recetas base)

Todas las fórmulas parten de una **base de 1 libra = 500 gr de harina**.
Las cantidades de los demás ingredientes están en **gramos**.

### 2.1 Francés

| Ingrediente | Cantidad (gr) |
|-------------|--------------:|
| Harina      | 500           |
| Mantequilla | 40            |
| Azúcar      | 20            |
| Sal         | 10            |
| Levadura    | 3,3           |
| Esencias    | 1             |

**Nota:**De una libra de masa salen:
- 3.3 panes de Francés Queso cada uno de 235 gr
- 5.8 panes de Francés Normal cada uno de 135 gr
- 11.5 panes de Francés pequeño cada uno de 70 gr

**Variantes:**
- **Francés Queso:** + 7 gr de queso duro
- **Francés Normal:** + 1.5 gr de ajonjolí
- **Francés pequeño**

## 3. Convenciones para el sistema

- **Moneda:** COP (pesos colombianos), sin decimales.
- **Unidad base de insumos:** libra = 500 gr (salvo empaques, que van por unidad).
- **Unidad base de fórmulas:** gramos, sobre una base de 500 gr de harina.
- **Grupos de insumos sugeridos:** harinas, lácteos/grasas, esencias, rellenos
  (bocadillo, arequipe, uvas pasas, chips), empaques, otros.
